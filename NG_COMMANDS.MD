# Services
### General
```
ng generate s --type=service --name=
```
### API
```
ng generate s --type=api --name=

# Components
### General
```
ng generate c --type=component -c=OnPush --standalone=false --style=scss -v=none --name=
```
### Page
```
ng generate c --type=page -c=OnPush --standalone=false --style=scss -v=None --name=
```

# Guard
```
ng generate guard  --type-separator=. --functional=false
